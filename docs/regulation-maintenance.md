# 내수면 규제 경계 검증·주간 갱신

범위: 상수원보호구역과 내수면 수상레저 금지구역. 바다 및 한국농어촌공사 관리 저수지의 추천·신규 조사 제외. 제외 정책은 기존 규제 도형을 삭제하거나 법적 금지 근거로 대체하지 않는다.

## 현재 검증 수준

VWorld 원본 유형 UMI100 필터, 전국 페이지 완전성, 좌표·폐합·누락 검사는 자동 수행한다. 이는 개별 고시도면 대조를 뜻하지 않는다. `data/regulation-audit/latest.json`에 구역별 도형 해시, 고시번호, 기간, 기구 유형, 검토 사유를 기록한다. 원문 링크 부재는 고시 자체가 없다는 의미가 아니다.

`tools/audit_regulations.py`는 도형을 수정하지 않는다. 자기 교차, 기간 경과, 개략 경계, 고시 원문 링크 누락을 검토 목록으로 만든다. 동력기구만 금지하는 구역을 카누 금지로 추론하지 않는다. 바다 레이어 `wlz.geojson`은 이 작업의 조사 범위에서 제외하며 내수면은 별도 원본 `data/wlz_inland.geojson`으로 점검한다.

## 매주 화요일 06:00 (한국 시간)

기존 launchd `kr.crowdbase.canoemap.protection-refresh`에서 실행:

1. 깨끗한 운영 브랜치 체크아웃에서 VWorld 전국 조회.
2. 유형·페이지 수·중복·좌표·구역 급감·지역 누락 검증. 실패 시 게시하지 않음.
3. 기존 회귀 검사와 규제 점검 검사 실행.
4. 전체 점검 보고서 생성. 경계 추가·변경·누락을 이전 보고서와 비교.
5. 데이터 변경과 점검 보고서를 Git에 기록. 누락·기간 종료를 고시 해제로 자동 해석하지 않음.

주간 작업은 **VWorld 조회와 내부 자료 검사**를 자동화한다. 전국 지자체 고시 사이트를 자동 탐색하거나 첨부도면을 자동 판독하지 않는다. 고시 대조 완료 상태는 근거 없는 자동 승격을 금지한다.

실행 로그: `~/Library/Logs/CanoeMapProtectionRefresh.log`
최종 실행 상태와 마지막 성공 시각: `~/Library/Caches/kr.crowdbase.canoemap.protection/status.json`
맥이 꺼져 있으면 지정 시각에 실행할 수 없으므로 마지막 성공 시각으로 누락 여부를 확인한다. 실패는 로그·상태 파일에 남긴다. 이메일 알림은 이번 범위에 포함하지 않는다.

## 공식 경계 확정 절차

도형 오류 및 기간 경과 구역 우선 → 관할기관 최신 변경·해제 고시와 첨부도면 확보 → 고시번호/적용기구/기간 확인 → 좌표계와 도면 기준점 대조 → 원본 보존 후 수정 → 변경 전후 경계 비교 → 근거 링크·대조일 기록.

단순 사각형·원형·물길 버퍼나 위성사진 물가를 공식 경계로 확정하지 않는다. 갱신 데이터 누락이나 API 실패를 해제로 처리하지 않는다. 공개 UI 문구·배치 변경은 별도 시안 승인 후 진행한다.
