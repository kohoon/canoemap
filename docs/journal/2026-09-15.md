## 결정·근거

- 두 선은 이름의 공백만 달랐으며 가장 가까운 끝점은 `[128.646165, 38.107106]`과
  `[128.644557, 38.10615]`로 약 176m 떨어져 있었다. 같은 이름의 주요 하천을 약 4km 이내에서 보완 연결하는
  기존 규칙 안에 있으므로, 별도 수계로 유지하지 않고 직선 연결했다.
- 전국 하천 원본 전체를 새로 수집하지 않고 해당 두 선만 기계적으로 병합해 다른 하천의 좌표·이름은 보존했다.
- 로드뷰 원본은 장소 근처 약 25m의 짧은 선이라 전국·권역 축척에서 투영 길이가 1픽셀보다 작아질 수 있었다.
  지리적 범위를 과장하지 않도록 선 좌표는 그대로 두고, 축척과 무관한 5px 원형 지점만 가시성 보조로 추가했다.

## 검증

- 생성 데이터에서 `양양남대천`이 213개 좌표를 가진 LineString 한 건이고 `양양 남대천` 이름은 남지 않았음을 확인했다.
- 회귀 테스트는 두 접합 좌표가 연속하며 거리가 200m 미만이고, 병합선이 기존 두 구간의 전체 위도 범위를 포함하는지 확인한다.
- 모바일 390×844 Playwright 공유 URL 검증에서 하천 객체 1건·연결망 1건, 강조선 2겹과 `양양남대천`
  포커스 표시를 확인했으며 JavaScript 페이지 오류는 0건이었다. 기존 오프라인·투어 화면 테스트도 함께 통과했다.
- 로그인 보호 장소 응답을 모사한 모바일 Playwright 검증에서 `로드뷰 구간` 체크박스를 직접 눌렀다. 레이어가 ON 되고,
  로드뷰 가능 1곳이 선 1개+원형 지점 1개로 표시되며 `1곳 표시` 안내와 JavaScript 오류 0건을 확인했다.
