  동일 수계 식별자·정확한 공유 노드(한탄강) 또는 정확히 이어지는 본류 way(수입천)가 확인된 두 곳은 아래처럼

## 선이 나뉘는 경우 점검

- **같은 이름의 다른 수계**: 전국에 반복되는 `금성천`, `역곡천`, `남강` 등은 위치가 떨어져 있으면 의도적으로
  별도 검색 결과로 유지한다. 이름은 동일 수계의 증거가 아니다.
- **OSM 이름·등급 변경**: `림진강/임진강`, `양양 남대천/양양남대천`, `river/stream` 전환처럼 실제 연결선의
  속성이 달라지면 정규화 또는 교차 등급 병합이 필요하다.
- **무명 중간 구간·저수지**: 이름 있는 선 사이가 무명 중심선이나 호수 면으로 저장되면 이름 기반 수집만으로는
  끊긴다. 홍천강·일리천처럼 실제 OSM 본류를 확인한 경우에만 강제 편입한다.
- **작은 좌표 간격·원천 누락**: 현재 동명 선이 여러 객체인 이름은 442개지만 대부분 별도 수계다. 끝점 간격이
  250m 미만인 점검 후보는 13개 이름(`도고천`, `오쇠천`, `녹양천` 등)이며, 실제 같은 물줄기인지 원천 대조 전에는
  자동 병합하지 않는다.
- **국경 절단**: 기존 대한민국 폴리곤 필터가 북한 구간을 제거하던 경우다. 이번 변경으로 실제 연결된 구성요소는
  경계를 넘어 유지한다.

### 사람이 이해해야 할 변경 이유

- 이전에는 카카오 로그인이 곧 이용 허용이었고, 앱 닉네임만 별도로 받았다. 접속 시트와 레거시 프로필 키에는
  원본 카카오 숫자 ID가 쓰였다. 이번 변경부터 카카오 인증과 마이카누 회원 상태를 분리한다.
- 기존 접속 시트는 과거 운영 기록으로 남기되 새 회원 DB로 일괄 복제하지 않는다. 확인 시점 기준 지도 로그인/방문
  이력은 40명, 535회다. 앞으로의 회원·접속 통계는 명시적으로 동의한 회원부터 새로 누적된다.

### 구현한 가입과 저장 방식

- 로그인 뒤 앱 닉네임, 서비스 이용 동의, 개인정보 수집·이용 동의를 모두 확인해야 가입된다. 기존 이용자도
  1회 재로그인과 동의를 거친다. 기존 닉네임은 입력 제안값으로만 읽는다.
- 회원 정본은 `member:<HMAC(카카오ID)>`에 저장한다. 값에는 원본 카카오 ID 없이 가명 회원번호, 닉네임,
  `active/withdrawn` 상태, 가입·동의·최근접속 시각, 로그인·방문 횟수, PC/모바일, 동의 버전만 둔다.
- Google Sheets와 GA4에는 원본 ID 대신 가명 회원번호를 보낸다. 관리자 회원관리 화면도 가명 번호와 전환 이후
  횟수만 보여준다. 기존 시트의 원본 ID를 코드나 저장소로 가져오지 않았다.

### 적용한 보안수단

- 무기한 `mc1` 토큰을 30일 만료 `mc2` HMAC 토큰으로 교체하고, 서버 비밀키가 없으면 인증을 허용하던 동작을
  실패 우선으로 바꿨다. 기존 세션은 재로그인이 필요하다.

  활성 회원으로 처리하지 않는 음성 회귀 테스트를 추가했다.
- 회원관리 API는 관리자 키, 허용 Origin, 요청 빈도 제한, 캐시 금지 헤더를 적용하며 원본 카카오 ID를 반환하지 않는다.

  옮긴다. 기존 Google Sheet는 제한된 관리자만 접근하는 과거 통계 원천으로 유지한다.
