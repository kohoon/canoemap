# 2026-09-16

## 한 일

- `주요 강·하천 (관리자)` 원천 범위를 대한민국 내부 선분에서 대한민국에 닿는 한반도 연결망으로 확장했다.
- 남북 경계를 넘는 임진강·북한강·남강(고성)·금성천·역곡천·인북천·사태천·사미천·판문천·한탄강·한강 하구
  11개 이름의 OSM 연결선을 북한 구간까지 반영했다.
- 북한의 `림진강`·혼합 표기를 `임진강`으로 정규화하고, 다음 전국 원천 갱신 때도 북한 연결망이 유지되게
  `tools/build_rivers.py`의 수집·선별 방식을 변경했다.

## 결정·근거

- OSM 이름만 같다는 이유로 북한의 모든 동명 하천을 합치지 않는다. 대한민국 내부 좌표를 포함하고, 같은 이름의
  선분 끝점이 약 200m 이내로 실제 연결되는 구성요소만 북한 구간까지 유지한다.
- 현재 `rivers.geojson`만 안전하게 갱신하는 `--extend-north` 모드를 두어 전국의 나머지 하천 원본은 바꾸지 않았다.
  다음 전체 원천 갱신은 한반도 범위를 조회한 뒤 대한민국에 닿는 연결망만 선별한다.
- 이름 있는 OSM 중심선이 경계 부근에서 끝나면 원칙적으로 제공된 형상까지만 표시한다. 다만 후속 원천 점검에서
  동일 수계 식별자·정확한 공유 노드(한탄강) 또는 정확히 이어지는 본류 way(수입천)가 확인된 두 곳은 아래처럼
  근거를 기록하고 예외 보정했다. 무명 수로를 임의로 따라가거나 지도를 가로지르는 직선은 만들지 않는다.

## 선이 나뉘는 경우 점검

- **같은 이름의 다른 수계**: 전국에 반복되는 `금성천`, `역곡천`, `남강` 등은 위치가 떨어져 있으면 의도적으로
  별도 검색 결과로 유지한다. 이름은 동일 수계의 증거가 아니다.
- **OSM 이름·등급 변경**: `림진강/임진강`, `양양 남대천/양양남대천`, `river/stream` 전환처럼 실제 연결선의
  속성이 달라지면 정규화 또는 교차 등급 병합이 필요하다.
- **무명 중간 구간·저수지**: 이름 있는 선 사이가 무명 중심선이나 호수 면으로 저장되면 이름 기반 수집만으로는
  끊긴다. 홍천강·일리천처럼 실제 OSM 본류를 확인한 경우에만 강제 편입한다.
- **작은 좌표 간격·원천 누락**: 현재 동명 선이 여러 객체인 이름은 442개지만 대부분 별도 수계다. 끝점 간격이
  250m 미만인 점검 후보는 13개 이름(`도고천`, `오쇠천`, `녹양천` 등)이며, 실제 같은 물줄기인지 원천 대조 전에는
  자동 병합하지 않는다.
- **국경 절단**: 기존 대한민국 폴리곤 필터가 북한 구간을 제거하던 경우다. 이번 변경으로 실제 연결된 구성요소는
  경계를 넘어 유지한다.

  객체는 그대로 유지됐다. 한강 하구의 세 조각이 한 연결망으로 합쳐져 전체 객체 수는 3,080개에서 3,078개가 됐다.

  금성천·역곡천이 별도 수계로 남는 음성 사례를 함께 확인했다.

## 후속 보정 — 한탄강·수입천 북한 구간

### 발견한 원인과 처리

- 한탄강 남한 구간의 국경 노드 `310637577`은 북한의 `한탄천` way `125984808`과 정확히 공유된다. 북한 쪽
  이름만 다르고 `name:en=Hantan River`, Wikidata `Q492822`가 동일하므로, 이 식별 조건을 만족하는
  `한탄천`만 검색명 `한탄강`으로 정규화했다. 단순히 이름이 `한탄천`이라는 이유로 다른 하천은 합치지 않는다.
- 이 연결로 한탄강은 336좌표·최고 위도 38.326729에서 543좌표·38.529824로 확장됐다. 북한의 이름 있는
  OSM 본류 끝까지 한 개 연결선으로 표시한다.
- 수입천의 이름 있는 way `372680760`은 국경 노드 `2504226676`에서 끝난다. 같은 노드부터 북한 상류로 이어지는
  이름 없는 `river` way `242986174`·`242986175`를 본류로 확인해 약 10km를 편입했다. 중간 공유 노드에서
  서쪽으로 갈라지는 way `242986177`은 지류라서 제외했다.
- 수입천은 153좌표·최고 위도 38.289983에서 213좌표·38.380405로 확장됐다. 전체 3,078개 하천 중 한탄강과
  수입천 두 객체만 교체됐고 나머지는 변경하지 않았다.
