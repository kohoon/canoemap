- Cloudflare의 `canoemap-github-deploy` API 토큰에 기존 `Cloudflare Pages: 편집` 권한을 유지하면서 `Workers 스크립트: 편집` 권한을 추가했다.
- 실패했던 GitHub Actions `Deploy worker` 실행을 재시도해 단위 테스트 34개와 Cloudflare Worker 배포가 모두 성공했다.
- `mycanoe-map` 운영 Worker 버전 `54cf8b7f-6cb8-46bd-95b6-d22c02540612` 반영을 확인했다.
- 앞으로 `workers/**`, `wrangler.toml`, 관련 Worker 테스트 또는 배포 워크플로가 변경되면 검증 후 Worker가 자동 배포된다.

## 선택 지점 토지소유 확인

### 한 일

- 모바일 더블탭·PC 우클릭으로 열리는 기존 주소 팝업에 `🏷 토지소유 확인` 버튼을 추가했다.
- Worker `/land-ownership`이 선택 좌표의 VWorld 연속지적도 PNU와 필지 도형을 찾고, 토지임야정보에서 소유구분·지목·면적·기준일을 조회하도록 구현했다.
- 결과를 국유지·지자체 소유·사유지·확인 불가로 단순화하고 선택 필지만 색상·선형으로 임시 강조한다.
- 소유자 식별정보는 응답에 포함하지 않고, 출입·진수·캠핑 허가와 별개라는 안내를 결과에 고정했다.

### 결정·근거

- 전국 토지소유 레이어는 카누 투어 계획에 불필요하고 지도 복잡도와 API 사용량만 늘리므로 제공하지 않는다.
- 기존 주소 조회 동작을 재사용해 새로운 제스처를 추가하지 않는다. 활성 거리측정 중 모바일 더블탭 차단 규칙도 유지한다.
- 공개 VWorld 키는 기존처럼 등록 도메인에 제한하며, 외부 API 호출은 Worker에서 수행하고 허용 Origin·좌표범위·호출 제한·1일 캐시를 적용한다.

### 미해결·다음 시작점

- 운영 배포 후 실제 하천변의 국유지·지자체 소유·사유지 표본을 각각 확인한다.
- 토지소유 구분은 이용 허가가 아니므로 하천구역·보호구역 등 별도 규제 판정과 자동 결합하지 않는다.
