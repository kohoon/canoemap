# 2026-09-25 작업 저널

## Cloudflare Worker 자동 배포 정상화

- Cloudflare의 `canoemap-github-deploy` API 토큰에 기존 `Cloudflare Pages: 편집` 권한을 유지하면서 `Workers 스크립트: 편집` 권한을 추가했다.
- 실패했던 GitHub Actions `Deploy worker` 실행을 재시도해 단위 테스트 34개와 Cloudflare Worker 배포가 모두 성공했다.
- `mycanoe-map` 운영 Worker 버전 `54cf8b7f-6cb8-46bd-95b6-d22c02540612` 반영을 확인했다.
- 앞으로 `workers/**`, `wrangler.toml`, 관련 Worker 테스트 또는 배포 워크플로가 변경되면 검증 후 Worker가 자동 배포된다.

## 선택 지점 토지소유 확인

### 한 일

- 모바일 더블탭·PC 우클릭으로 열리는 기존 주소 팝업에 `🏷 토지소유 확인` 버튼을 추가했다.
- 브라우저가 선택 좌표의 VWorld 연속지적도 PNU와 필지 도형을 찾고, 토지임야정보에서 소유구분·지목·면적·기준일을 조회하도록 구현했다.
- 결과를 국유지·지자체 소유·사유지·확인 불가로 단순화하고 선택 필지만 색상·선형으로 임시 강조한다.
- 소유자 식별정보는 응답에 포함하지 않는다.

### 결정·근거

- 전국 토지소유 레이어는 카누 투어 계획에 불필요하고 지도 복잡도와 API 사용량만 늘리므로 제공하지 않는다.
- 기존 주소 조회 동작을 재사용해 새로운 제스처를 추가하지 않는다. 활성 거리측정 중 모바일 더블탭 차단 규칙도 유지한다.
- 공개 VWorld 키는 기존 역지오코딩·검색과 동일하게 등록 도메인에 제한하고 JSONP로 호출한다. VWorld 원서버가 Cloudflare 네트워크 요청을 520으로 거부해 Worker 중계 대신 공식 샘플과 같은 브라우저 JSONP 방식을 사용한다.

### 미해결·다음 시작점

- 운영 배포 후 실제 하천변의 국유지·지자체 소유·사유지 표본을 각각 확인한다.
- 토지소유 구분은 이용 허가가 아니므로 하천구역·보호구역 등 별도 규제 판정과 자동 결합하지 않는다.

## 토지소유 팝업 UI 정리

- 주소복사·토지소유 버튼을 한 줄 액션 영역으로 묶고 버튼 문구를 짧게 정리했다.
- 결과 카드는 제목·소유 배지·필지 항목·공식 링크의 시각적 위계를 분리하고 모바일 폭에서 줄바꿈이 자연스럽도록 간격과 글자 크기를 조정했다.
- 토지이음 링크는 일반 액션 버튼 스타일을 재사용하지 않고 전용 흰색 보조 버튼으로 변경했다.
- 사용자 요청에 따라 결과 카드의 출입·진수·캠핑 허가 관련 주의문을 제거했다.
- 토지정보 카드가 작은 필지 경계를 덮지 않도록 주소 팝업을 선택 좌표에서 위로 52px 이격하고 화면 가장자리에서는 자동으로 안쪽에 유지되도록 했다.

## 오월리 만입부 물길 연결 복구

- 오월리를 도착지로 선택하면 물길이 본류에서 끝나고 도착지까지 회색 접근선으로 표시되는 문제를 수정했다.
- 원인은 육지 관통을 막기 위한 오월1교 대각선 경계가 OSM에 등록된 실제 수로 중심선까지 차단한 것이었다.
- 경계는 수면 격자 경로와 직선 단축에만 적용하고, `waterway` 중심선 그래프는 오월교 아래 실제 물길을 따라 통과하도록 변경했다.
- 오월리 좌표로 종료되는 회귀 테스트와 실제 OSM 응답을 사용한 브라우저 검증에서 접근선 없이 도착지까지 물길이 연결되는 것을 확인했다.

## 만입부·반도 도착지 연결 일반화

- 특정 지점 예외에 그치지 않고, Overpass 물길 중심선과 도착지 사이의 직선 연결이 불가능한 경우 수면 격자 위 우회 경로를 자동 탐색하도록 했다.
- 도착지↔중심선 직선이 450m를 넘거나 반도·섬을 가로질러도, 같은 수면 안의 거리가 최대 약 2.2km이면 육지를 피한 실선 물길로 연결한다.
- 중심선 끝에서 만입부 안쪽 도착지까지 육지를 돌아가는 합성 수면 사례를 회귀 테스트로 추가해, 회색 접근선으로 퇴행하거나 육지를 관통하는 변경을 자동 탐지한다.

## 주소·토지정보 카드 이동

- 주소 팝업 상단에 `끌어서 이동` 손잡이를 추가했다.
- PC에서는 마우스 드래그, 모바일에서는 터치 드래그로 카드를 옮겨 가려진 필지 경계와 지도를 확인할 수 있다.
- 카드가 화면 밖으로 빠져 닫히지 않는 상태가 되지 않도록 10px 안쪽으로 이동 범위를 제한했다.
- 팝업을 닫거나 다시 열면 위치를 초기화하고, 드래그 이벤트도 정리해 반복 조회 시 이벤트가 쌓이지 않게 했다.
- 카드의 `keepInView` 기능이 지도를 다른 지역으로 이동한 뒤 다시 선택 지점으로 끌어오는 문제를 해제했다. 카드가 열려 있어도 지도를 자유롭게 팬하고, 카드는 선택 좌표와 함께 화면 밖으로 빠진다.
- 회색 배경 상자와 `끌어서 이동` 문구가 카드 제목보다 두드러지던 UI를 제거하고, 상단 중앙의 얇은 34px 손잡이로 교체했다. 드래그 기능과 접근성 이름은 유지한다.

## 변동 호안 런칭·랜딩까지 코스 연결

- 인제 관대리처럼 지도 수면 경계 밖에 표시되지만 실제 수위에 따라 물가가 될 수 있는 런칭·랜딩을 선택하면, 물길이 가장 가까운 수면 지점에서 끝나던 동작을 수정했다.
- 수면 검증이 되지 않은 마지막 연결도 회색 점선으로 분리하지 않고 사용자가 선택한 좌표까지 코스 실선으로 이어지게 했다.
- 마지막 연결 거리를 구간 거리·누적 거리·코스 저장·공유 경로에 모두 포함한다.
- 수면 내부에서는 기존 반도·섬 우회와 육지 관통 방지 로직을 그대로 우선 적용하며, 가까운 물길 자체를 찾지 못하는 지점은 계속 오류로 처리한다.
- 지도 수면 밖의 합성 랜딩 좌표까지 경로가 끝나고 접근선이 남지 않는 브라우저 회귀 테스트를 추가했다.
- 운영·투어·테스트 지도를 재생성하고 Python 단위 테스트 35개와 전체 오프라인 브라우저 테스트 22개를 통과했다.

## 동일 지명 검색결과 지역 힌트

- VWorld 장소검색에서 `와룡산`처럼 주소 없이 같은 이름만 반복되는 결과를 좌표별로 역지오코딩하도록 보완했다.
