# 2026-09-30 작업 기록

## 패들링 스쿨 카카오 로그인 필수화

- 카누맵과 패들링 스쿨·용어사전이 동일 출처 `mc_user` 세션을 공유한다. 카카오 로그인 콜백도 두 페이지에서 처리한다.
- Worker `/paddling-state`에서 활성 회원 토큰을 확인할 때까지 학습 화면을 숨기고, 비회원·만료 세션·API 장애는 로그인 또는 재시도 안내로 처리한다.
- 비회원 진도 저장과 익명 패들링 방문 기록을 중단했다. 기존 회원의 진도·즐겨찾기·최근 학습은 유지한다.
- 다른 탭의 카누맵에서 로그인 상태가 바뀌면 열린 패들링 스쿨·용어사전도 즉시 다시 검증한다.
- PC·모바일 및 비회원·무효 세션·로그인 콜백·다른 탭 로그아웃·용어사전 브라우저 회귀검사 5개 통과. 정적 HTML의 원본 학습 데이터까지 비공개하려면 콘텐츠를 인증 API로 이전해야 한다.

## 카누 패들링 스쿨 학습·수상 연습 개편

- 55개 기술을 목적별로 따라갈 수 있는 6개 학습 코스를 추가했다.
- 기술마다 `연습 중`과 `익힘` 상태를 저장하고 코스별 진행률과 이어볼 기술을 표시한다.
- 배 위에서 잠깐 확인할 수 있도록 `준비 → 동작 → 확인` 3단계 고대비 수상 연습 카드를 추가했다.
- 수상 연습 카드는 이전·다음 기술 이동, 화면 꺼짐 방지 요청, 정지 후 확인 안전 안내를 제공한다.
- 비회원 진도는 기기에, 회원 진도는 기존 `/paddling-state` 계정 상태에 저장한다.
- 기존 YouTube 영상 50개의 공개 상태를 전수 확인했고, ACA 교육 영상 목록을 근거로 PaddleTV의 안전·장비·기본기 영상 8개를 추가했다.
- 데스크톱과 모바일에서 학습 코스, 수상 연습 카드, 진도 저장, 가로 넘침을 자동 검사한다.
- 학습 코스 제목의 생활어 표현을 카누 용어에 맞춰 `평수 카누잉`, `유수 카누잉 입문`으로 정리했다.
- 패들링 스쿨 대표 사진의 인물을 빌 메이슨 시대의 클래식 캐나다 카누이스트 분위기로 교체하고, 기존 카누·비버테일 패들·호수 구도와 1672×941 공유 이미지 규격은 유지했다.
- 패들링 스쿨 모바일 UI를 개편했다. 대표 이미지의 기본 figure 여백을 제거하고, 학습 코스를 가로 스와이프 카드로 압축했으며, 기술 카드를 간결하게 만들고 학습 코스·전체 기술·검색·카누맵 하단 빠른 메뉴를 추가했다.

## 카누맵 투어 통합 베타

- `canoe.crowdbase.kr/?tour=1`에서 기존 지도·계정·코스·범례를 그대로 사용하며 투어 기록을 시작한다. 우상단에 투어 모드 진입·복귀 버튼을 추가했다.
- 마이페이지에 투어 기록·실측 누적거리·활동시간을 통합했다. 기록 지도 보기, 공유 해제, 삭제 기능은 기존 Worker 계약을 사용한다.
- 기록 시작 전에 정확한 위치·이동경로의 저장과 공유 범위를 안내하고 명시적 체크를 요구한다. 첫 GPS 위치 정확도 50m 이내일 때 시작하며, 기록 중 GPS 오류·수신 중단을 표시한다.
- GPS 실측 경로와 물길 추정 경로를 분리해 저장한다. 통계와 새로운 `board_measured_v2` 랭킹에는 실측 거리만 들어간다. 이전 추정 기록은 실측 통계에서 제외한다.
- `tour.crowdbase.kr`은 미전송 대기열·진행 중 기록이 있는 기기에 복구용 기존 화면을 제공하고, 그 외에는 통합 모드로 이동한다.
- 온라인 확인 요청을 작은 `health.txt`로 바꾸고 파비콘을 명시했다.
- 투어 코스 지정 단계에서 런칭·랜딩지 아이콘 클릭으로 등록 좌표를 출발지·도착지로 선택할 수 있게 했다. 지도 빈 곳을 찍는 방식도 유지한다.
- 현재 위치 추적에서 GPS 시간 초과·일시적인 위치 미확인을 권한 거부로 잘못 표시하고 추적을 중단하던 동작을 수정했다. 일시 오류는 마지막 위치를 유지하며 재수신하고, 실제 접근 차단에만 권한·기기 설정 안내를 표시한다.
- 투어 바가 하단 안내문을 가리던 문제를 바 높이 기반 배치로 수정하고, 긴 코스 호버 말풍선은 화면 가장자리에서 방향을 바꾸고 줄바꿈하며 런칭 아이콘 위에 표시한다.
- 범례를 기본 접힘으로 바꾸고 펼친 범례의 최대 높이를 실제 우상단 메뉴 높이에 맞췄다. 투어 모드에서 접힌 범례는 기록 바 위에 두며, 범례를 펼칠 때는 기록 바와 짧은 안내문을 잠시 숨겨 겹침을 막는다.

## 검증

- Python 68개 단위 테스트 통과.
- 통합 투어 브라우저 테스트: PC 1280px, 모바일 390px에서 모드 진입, 위치 동의, GPS 기록, 실측 요약, 가로 넘침 없음 확인.
- 기존 오프라인 회귀 34개와 통합 투어 브라우저 검사 3개를 순차 실행해 총 37개 통과.
- Worker 메모리 KV 검사에서 실측·추정 분리, 멱등 저장, 비정상 좌표 거절, 기존 대기열 형식의 GPS 원본 우선 저장 확인.

## 후속 현장 검증

- iPhone Safari와 Android Chrome에서 화면 잠금·전화 수신·통신 단절·2시간 이상 기록을 실제 수상에서 시험한다.
- 웹 브라우저의 백그라운드 GPS 연속성은 보장되지 않으므로, 현장 결과에 따라 네이티브 기록 방식 도입 여부를 결정한다.
