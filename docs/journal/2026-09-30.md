# 2026-09-30 작업 기록

## 카누 패들링 스쿨 학습·수상 연습 개편

- 55개 기술을 목적별로 따라갈 수 있는 6개 학습 코스를 추가했다.
- 기술마다 `연습 중`과 `익힘` 상태를 저장하고 코스별 진행률과 이어볼 기술을 표시한다.
- 배 위에서 잠깐 확인할 수 있도록 `준비 → 동작 → 확인` 3단계 고대비 수상 연습 카드를 추가했다.
- 수상 연습 카드는 이전·다음 기술 이동, 화면 꺼짐 방지 요청, 정지 후 확인 안전 안내를 제공한다.
- 비회원 진도는 기기에, 회원 진도는 기존 `/paddling-state` 계정 상태에 저장한다.
- 기존 YouTube 영상 50개의 공개 상태를 전수 확인했고, ACA 교육 영상 목록을 근거로 PaddleTV의 안전·장비·기본기 영상 8개를 추가했다.
- 데스크톱과 모바일에서 학습 코스, 수상 연습 카드, 진도 저장, 가로 넘침을 자동 검사한다.
- 학습 코스 제목의 생활어 표현을 카누 용어에 맞춰 `평수 카누잉`, `유수 카누잉 입문`으로 정리했다.
- 패들링 스쿨 대표 사진의 인물을 빌 메이슨 시대의 클래식 캐나다 카누이스트 분위기로 교체하고, 기존 카누·비버테일 패들·호수 구도와 1672×941 공유 이미지 규격은 유지했다.
- 패들링 스쿨 모바일 UI를 개편했다. 대표 이미지의 기본 figure 여백을 제거하고, 학습 코스를 가로 스와이프 카드로 압축했으며, 기술 카드를 간결하게 만들고 학습 코스·전체 기술·검색·카누맵 하단 빠른 메뉴를 추가했다.
