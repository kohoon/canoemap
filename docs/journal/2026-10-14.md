# 2026-10-14 · 등록 코스로 카누잉 다이어리 작성

## 한 일
- 카누맵 기록하기와 다이어리에 ‘등록 코스로 기록’ 진입점을 추가했다.
- 회원 본인·운영자 KV 코스만 인증해 목록과 선택한 코스 좌표를 순차 조회한다.
- 선택 시점의 코스 경로를 비공개 다이어리에 저장하고 수정·JSON 백업/복원·GPX 계획 경로 내보내기를 지원한다.

## 결정·근거
- 등록 코스는 실제 GPS 운항 트랙이 아니므로 화면의 점선·설명과 GPX `<rte>`로 구분한다.
- 코스가 후에 변경·삭제되어도 이전 다이어리가 열리도록 경로 스냅샷을 보존한다.
- 다른 회원의 개인 코스는 조회·기록할 수 없다. 목록에는 좌표 대신 요약만 내려 조회 부담을 줄인다.
- 기존 브라우저가 오래된 다이어리 스크립트를 계속 쓰지 않도록 앱 캐시 버전을 올리고, 다이어리 정적 파일은 온라인 우선으로 갱신한다.

## 검증·다음 시작점
- 다이어리 API·내보내기 단위 테스트, 브라우저 PC/모바일 10건, Python 전체 85건 통과.
- 지도 산출물의 생성 스크립트는 최신 운영 산출물보다 뒤처져 있다. 후속 작업에서 빌드 소스와 현재 운영 HTML의 차이를 별도 검토해야 하며, 이번 배포는 최신 운영 HTML에 해당 진입점만 적용했다.
