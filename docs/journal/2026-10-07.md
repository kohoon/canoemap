## 겹친 카누잉 코스의 교차 색상 줄무늬

- 현재 지도에 보이는 코스들의 경로를 비교해 일정 길이 이상 같은 물길을 공유하는 구간만 검출하고, 해당 구간 위에 참여 코스 색상을 짧은 교차 줄무늬로 표시한다. 두 코스뿐 아니라 세 코스 이상도 순서대로 번갈아 표시한다.
- 경로가 잠깐 교차하는 지점, 떨어진 평행 구간, 코스 단독 구간에는 줄무늬를 그리지 않는다. 기존 코스선의 클릭·호버 및 3km 방향 꺾쇠는 유지한다.
- 코스 표시/숨김·즐겨찾기 필터·공유 코스 집중 보기·삭제에 맞춰 줄무늬를 다시 계산한다. 코스 원본 좌표와 거리 데이터는 변경하지 않았다.
- 겹침·역방향·세 코스·교차 제외 브라우저 검사와 기존 PC·모바일 회귀검사를 통과했다.

## 회원 장소 제안의 정확한 위치 확인

- 주소만으로 제안 지점을 찾기 어려운 문제를 해결했다. 관리자 제안함에 제안자가 찍은 원래 좌표를 6자리로 강조하고, 해당 지점에 핀이 뜨는 카누맵 링크를 추가했다.
- `?pin=위도,경도`로 지도를 열면 그 좌표를 중심으로 확대하고 빨간 십자 핀과 좌표 툴팁을 표시한다. 회원 제안 입력창에도 전송될 좌표를 보여준다.
- 새 제안의 시트·기존 메일에는 카누맵 위치 URL을 설명에 포함해 전달한다. Apps Script 메일 템플릿에도 전용 위치 버튼을 추가했으며 이 버튼은 스크립트 재배포 후 적용된다.
- 관리자 모바일 화면, 위치 링크 지도 표시, 메일 내용 및 Worker 제안 회귀검사를 통과했다.

## 최근 추가된 곳들 항목별 1회 안내

- 회원 접속 때 같은 최근 코스·런칭/랜딩지가 세션마다 다시 나타나던 동작을 수정했다.
- 회원별로 표시 완료한 `course:<ID>`·`place:<ID>`를 별도 KV 키에 저장하고, 조회 시 이미 안내한 항목을 제외한다. 브라우저에도 회원별 확인 목록을 보조 저장해 같은 기기에서 서버 반영 지연 중 재표시를 막는다.
- 목록을 실제 화면에 렌더링한 뒤 확인 요청을 보내며, 새 항목이 없을 때는 자동 팝업을 띄우지 않는다. `새소식` 수동 조회도 아직 안내하지 않은 항목만 보여준다.
- 확인 요청은 회원 인증·허용 출처·속도 제한을 거치고, 현재 안내 가능한 항목 ID만 수용한다.
- Worker 회귀검사와 PC·모바일 브라우저 검사에서 재표시 방지와 신규 항목 표시를 확인했다.

## 최근 등록 장소가 목록에서 사라지는 문제 보완

- 자동 안내에서 확인 처리된 장소도 사용자가 `새소식 → 최근 추가된 곳들`을 직접 열면 최근 등록 이력(종류별 최대 20개)으로 다시 볼 수 있게 분리했다. 수동 조회는 확인 상태를 변경하지 않는다.
- 원본 장소 목록 동기화로 새 ID가 추가된 경우에도 서버가 등록 시각을 별도로 기록하고 최근 목록에 포함한다. 최초 원본 반영은 과거 장소를 일괄 신규로 알리지 않도록 제외한다.
- 도천리 산 376 장소의 실제 운영 데이터 경로는 관리자 인증 자료가 없어 직접 확인하지 못했다. 관리자 화면의 신규 등록 장소라면 이번 수동 이력 조회로 다시 확인할 수 있다.
- Worker 회귀검사, PC·모바일 브라우저 검사 및 Python 전체 단위검사(85개)를 통과했다.

## 미분류 코스의 성격 아이콘 숨김

- 수면 환경을 입력하지 않은 기존 코스에는 `?` 아이콘과 ‘수면 환경 미확인’ 문구를 표시하지 않도록 변경했다.
- 목록·선택 패널·전체 상세창·지도 호버 설명에서 빈 메타데이터 줄이나 앞쪽 구분점이 남지 않게 처리했다. 평수·유수·급류가 입력된 코스에는 해당 아이콘을 계속 표시한다.

## 번버리Pick 표기 통일

- 코스 카테고리·필터·새 코스명 표기를 `번버리Pick`으로 변경했다.
- 기존 `번버리 픽` 이름은 저장 데이터를 일괄 수정하지 않고 표시·분류 시 새 표기로 정규화한다. 공유 정보와 최근 추가 목록에도 새 이름을 사용한다.
- 운영자 전용 카테고리 보호는 기존 표기와 새 표기를 모두 인식하도록 유지했다.

## 관리자 장소 제안함

- 회원 장소 제안은 런칭지·랜딩지·지형지물 유형과 이름·설명·좌표·사진을 담아 개별 접수 기록으로 저장한다. 관리자 검토 전에는 지도에 공개하지 않고 기존 카카오메일 알림도 유지한다.
- `/admin/` 관리자 페이지에서 접수 내역을 확인하고 이름·유형·좌표·설명을 교정한 뒤 승인하거나 반려할 수 있게 했다. 승인하면 런칭·랜딩은 장소 데이터, 지형지물은 지형지물 데이터에 등록된다. 검토 상태와 메모는 접수 기록에 남긴다.
- 관리자 키 검증, 제안 속도 제한, 입력값 검증, 목록 페이지네이션을 적용하고 서버·모바일 브라우저 회귀검사를 추가했다. 과거 구글시트 제안은 기존 시트에 남으며 새 제안부터 관리자 페이지로 접수된다.
