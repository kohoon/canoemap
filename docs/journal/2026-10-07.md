# 2026-10-07

## 최근 추가된 곳들 항목별 1회 안내

- 회원 접속 때 같은 최근 코스·런칭/랜딩지가 세션마다 다시 나타나던 동작을 수정했다.
- 회원별로 표시 완료한 `course:<ID>`·`place:<ID>`를 별도 KV 키에 저장하고, 조회 시 이미 안내한 항목을 제외한다. 브라우저에도 회원별 확인 목록을 보조 저장해 같은 기기에서 서버 반영 지연 중 재표시를 막는다.
- 목록을 실제 화면에 렌더링한 뒤 확인 요청을 보내며, 새 항목이 없을 때는 자동 팝업을 띄우지 않는다. `새소식` 수동 조회도 아직 안내하지 않은 항목만 보여준다.
- 확인 요청은 회원 인증·허용 출처·속도 제한을 거치고, 현재 안내 가능한 항목 ID만 수용한다.
- Worker 회귀검사와 PC·모바일 브라우저 검사에서 재표시 방지와 신규 항목 표시를 확인했다.

## 미분류 코스의 성격 아이콘 숨김

- 수면 환경을 입력하지 않은 기존 코스에는 `?` 아이콘과 ‘수면 환경 미확인’ 문구를 표시하지 않도록 변경했다.
- 목록·선택 패널·전체 상세창·지도 호버 설명에서 빈 메타데이터 줄이나 앞쪽 구분점이 남지 않게 처리했다. 평수·유수·급류가 입력된 코스에는 해당 아이콘을 계속 표시한다.

## 번버리Pick 표기 통일

- 코스 카테고리·필터·새 코스명 표기를 `번버리Pick`으로 변경했다.
- 기존 `번버리 픽` 이름은 저장 데이터를 일괄 수정하지 않고 표시·분류 시 새 표기로 정규화한다. 공유 정보와 최근 추가 목록에도 새 이름을 사용한다.
- 운영자 전용 카테고리 보호는 기존 표기와 새 표기를 모두 인식하도록 유지했다.
