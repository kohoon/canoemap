- 트립과 자유 투어 파생 코스에 `clientId` 멱등 처리를 넣어 재전송이 중복 기록으로 이어지지 않게 했다.

## 결정·근거

- OpenStreetMap 표준 타일 서버는 대량 다운로드·오프라인 선저장을 허용하지 않으므로 래스터 타일을 저장하지 않는다.
  프로젝트가 이미 배포하는 OSM 기반 하천·도로 벡터를 범위별 간이 배경으로 재사용한다.
- 전국 도로 원본은 6MB 이상이지만 코스와 교차하는 선분만 잘라 IndexedDB에 저장한다. 법규·안전 GeoJSON은 기존
  팝업과 스타일을 그대로 재사용하기 위해 CacheStorage에 원본 응답을 보관한다.
- 브라우저의 `navigator.onLine`만으로 통신 가능 여부를 단정하지 않고, Service Worker가 캐시하지 않는 동일출처
  probe도 확인한다. 식별자만으로 로그인 활성 상태를 판단하지 않고 현재 로그인 토큰은 서버 전송 시 다시 검증한다.
- 오프라인 투어 대기열에는 토큰을 기록하지 않는다. 서버는 동일 사용자·동일 `clientId`를 확인해 이미 저장된 현재
  기록이면 성공으로 응답하고 집계·피드를 다시 늘리지 않는다.
