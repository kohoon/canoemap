# 2026-09-26 작업 저널

## 과거 위성영상 이동·비교 동작 수정

- 과거 위성영상 레이어가 기능을 연 최초 위치 주변의 좁은 범위에만 생성되어, 지도를 이동하면 현재 영상으로 되돌아가 보이던 원인을 수정했다.
- 선택한 ESRI Wayback 배포본을 지도 전역 타일 레이어로 유지해 다른 강·호수로 이동해도 같은 과거 배포본을 계속 확인할 수 있게 했다.
- 배포본 선택 시 과거 영상을 지도 전체에 표시하는 방식을 기본값으로 변경했다.
- 필요할 때 `현재와 비교`를 선택하면 기존처럼 현재 영상과 과거 영상을 좌우 반반으로 비교할 수 있다.
- 과거 영상을 연 지점에서 부산까지 이동해도 선택 배포본과 레이어가 유지되는 브라우저 회귀 테스트를 추가했다.
- 서비스 워커 앱 캐시 버전을 올려 기존 캐시가 변경된 지도 UI를 가리지 않게 했다.
