# 2026-09-26 작업 저널

## 과거 위성영상 이동·비교 동작 수정

- 과거 위성영상 레이어가 기능을 연 최초 위치 주변의 좁은 범위에만 생성되어, 지도를 이동하면 현재 영상으로 되돌아가 보이던 원인을 수정했다.
- 선택한 ESRI Wayback 배포본을 지도 전역 타일 레이어로 유지해 다른 강·호수로 이동해도 같은 과거 배포본을 계속 확인할 수 있게 했다.
- 배포본 선택 시 과거 영상을 지도 전체에 표시하는 방식을 기본값으로 변경했다.
- 필요할 때 `현재와 비교`를 선택하면 기존처럼 현재 영상과 과거 영상을 좌우 반반으로 비교할 수 있다.
- 과거 영상을 연 지점에서 부산까지 이동해도 선택 배포본과 레이어가 유지되는 브라우저 회귀 테스트를 추가했다.
- 서비스 워커 앱 캐시 버전을 올려 기존 캐시가 변경된 지도 UI를 가리지 않게 했다.

## 코스 방향 표시 레이어 순서 고정

- 코스 방향 꺾쇠를 일반 오버레이 패널에서 별도의 `courseDirectionPane`으로 분리했다.
- 방향 표시는 모든 코스 선과 수계 오버레이보다 위에, 런칭·랜딩 등 장소 마커보다 아래에 나타나도록 고정했다.
- 방향 표시 패널의 포인터 이벤트를 끄고 기존 코스 클릭·호버 동작이 가려지지 않게 했다.

## 회원·커뮤니티·코스·투어 모집 고도화 기획

- 현재 회원가입·마이페이지·즐겨찾기·평면 코멘트·정적/KV 코스 구조를 점검했다.
- 회원가입 선택 프로필, 보관함과 내가 만든 코스 분리, 공식 안내와 1단계 답글, 관리자 코스 발행, 시리즈·활동 유형별 지도 필터를 하나의 계획으로 정리했다.
- 운영자 메시지와 투어 신청·승인·대기·취소를 연결하고 회원 간 자유 DM은 신고·차단 운영체계가 갖춰질 때까지 보류하도록 제안했다.
- 신규 댓글 관계·메시지·투어 모집은 KV 배열 대신 D1을 정본으로 사용하고, 기존 지도 원천·공개 경로는 현재 구조를 유지하는 단계적 이행안을 작성했다.
- 실제 회원 100명 이상 운영을 전제로 회원 1,000명·동시 사용자 100명까지의 확장 여유, 역할 기반 관리자 권한,
  세션 보강, 중앙 요청 제한, 개인정보 암호화·자동 파기, 페이지네이션·Queue, 부하 테스트·복구 훈련·출시 보안 게이트를 추가했다.

## 내 위치 실시간 이동 반영

- 내 위치 버튼을 일회성 조회에서 고정밀 연속 GPS 추적으로 변경했다.
- 위치가 갱신될 때 카누 마커와 정확도 원을 다시 만들지 않고 좌표·반경만 갱신하며, 지도 중심이 최신 위치를 따라가게 했다.
- 사용자가 지도를 직접 끌면 추적을 종료해 다른 지역을 보려는 동작과 충돌하지 않게 했다.
- 추적 중 버튼 색상과 접근성 상태를 추가하고, 연속 추적·마커 재사용·드래그 종료에 대한 회귀 테스트를 추가했다.

## 이동 환경별 현재 위치 아이콘

- 현재 GPS 좌표가 도로 가까이이면 테슬라 모델 Y, 강·하천 가까이이면 마이카누, 둘 다 아니면 사람 아이콘으로 표시하도록 변경했다.
- 기존 `roads.geojson`·`rivers.geojson`을 추적 시작 시 한 번 불러오고 현재 위치 약 5km 주변 구간만 추려 거리 판정해, 위치가 갱신될 때 전국 선형 자료를 반복 탐색하지 않게 했다.
- 차량 수준 속도는 도로 자료가 성긴 구간의 보조 근거로 사용하고, GPS 정확도에 따라 도로·수면 판정 반경을 조절한다.
- 서로 다른 환경 판정이 두 번 연속일 때 아이콘을 바꿔 도로와 강안 경계에서 표시가 빠르게 깜빡이지 않도록 했다.
