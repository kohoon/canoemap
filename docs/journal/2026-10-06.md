- PC 코스 패널 도입 뒤 지도 코스 선 클릭이 패널 선택만 수행하고 전체 상세를 열지 않던 동작을 복원했다.
- PC 코스 목록도 항목을 한 번 누르면 선택·지도 이동과 함께 전체 상세가 열리도록 했다. 기존 `전체 상세` 버튼은 유지한다.

## 코스 연결 방식 선택 UI

- 기존 단일 `물길`/`직선` 토글 버튼을 `코스 연결 방식` 제목과 `물길 따라`·`직선 연결` 두 선택 버튼으로 바꿨다.
- 현재 방식은 체크 표시, 강조색, `aria-pressed`로 함께 표시한다. 선택값의 기기 저장과 측정 중 방식 변경은 유지한다.
- PC·모바일, 선택값 재접속 유지까지 브라우저 회귀 테스트 6건을 통과했다.

## 최근 추가된 곳들

- 회원 접속 후 신규 회원 튜토리얼이 끝나면, 세션당 한 번 `최근 추가된 곳들`을 자동으로 표시한다. 공유 링크로 코스·장소를 바로 연 경우와 투어 모드에서는 자동 표시하지 않는다.
- 지도 왼쪽 `새소식`에서 공지사항과 최근 추가 목록을 다시 열 수 있다. 최근 목록에서 코스 또는 런칭·랜딩지를 누르면 해당 상세 링크로 이동한다.
- 목록에는 관리자 운영 엑스페디션 코스와 관리자 신규 등록 런칭·랜딩지만 각 최대 4개씩 표시한다. 다른 회원의 개인 코스, 후보지, 삭제된 장소는 노출하지 않는다. 등록 시각이 확인되는 항목만 최신순으로 정렬한다.
- `/recent-additions` API는 회원 세션과 허용된 출처를 검사하며 응답을 캐시하지 않는다. 새 장소의 등록 시각은 서버에서 기록한다.
- Worker 회귀검사와 PC(1280px)·모바일(390px) 브라우저 검사, 기존 코스 패널 브라우저 검사를 통과했다.
