# 2026-09-29 작업 저널

## 행정구역 검색과 경계 강조

- 통합검색에 도·시·군·구·읍·면·동 행정구역 결과를 추가했다.
- `리`는 VWorld 행정구역 검색의 직접 결과에 없어서 지번·장소 주소에서 법정리를 추출하고 같은 전체 주소를 중복 제거해 표시하도록 보완했다.
- 같은 이름의 지역을 구분할 수 있도록 도부터 해당 행정구역까지의 전체 주소와 행정단계를 보조 문구로 표시한다.
- 결과 선택 시 VWorld의 시도·시군구·읍면동·리 실제 경계 폴리곤을 불러와 반투명 청록색으로 강조하고 해당 영역에 맞춰 이동한다.
- 수원시·청주시처럼 일반구로 분할된 시는 여러 구를 하나의 시 검색 결과와 전체 경계로 묶는다.
- 지도 조작은 막지 않으며, 상단 현재 지역 표시의 닫기 버튼으로 강조를 해제한다.
- 모바일에서 결과가 화면을 넘지 않도록 검색 결과 영역에 최대 높이와 내부 스크롤을 적용했다.

## 행정구역 경계 디자인 B안 확정

- 내부 반투명 채움을 제거했다.
- 흰색 10px 후광 위에 청록색 4px 중심선을 겹쳐 위성지도와 일반지도에서 모두 선명한 이중 대비선으로 변경했다.

## 연천군 경계 원본 조각 정리

- VWorld 연천군 경계가 본체 1개와 작은 분리 조각 264개, 본체 내부 링 13개로 구성된 것을 확인했다.
- 표시용 경계에서는 내부 링을 제거하고, 가장 큰 외곽면이 전체 면적의 97% 이상이면 대표 외곽면만 표시하도록 변경했다.
- 여러 섬의 면적 비중이 분산된 행정구역은 분리된 외곽면을 유지해 섬 지역이 사라지지 않도록 했다.

## 접경지역 군사분계선 경계 보정

- 연천군 본체 폴리곤의 북쪽에 과거 행정구역과 필지 조각이 남아 복잡하게 표시되는 원인을 확인했다.
- OpenStreetMap의 남한측·북한측 DMZ 면 관계가 공통으로 사용하는 선형만 추출해 `data/military_demarcation_line.geojson`으로 저장했다.
- 파주·연천·철원·화천·양구·인제·고성의 행정구역 강조는 군사분계선 북측을 잘라내고, 잘라낸 구간은 실제 군사분계선 좌표를 따라 연결하도록 했다.
- VWorld 원본은 변경하지 않고 표시용 경계에만 보정을 적용했다. 실제 연천군 원본 10,273개 좌표를 검증한 결과 군사분계선 북측 잔존 좌표는 0개다.
