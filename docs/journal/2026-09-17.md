## 관리자 전용 캠핑사이트와 지도 화면 복원

- 컨펌한 시안대로 지형지물 등록 유형에 짙은 초록색 `🏕️ 캠핑사이트`를 추가했다. 이름은 필수, 메모는 선택이며
  등록창의 3열 유형 목록 마지막 줄 중앙에 둔다. 초기 운영 단계에는 관리자에게만 마커·팝업·검색 결과를 표시한다.
- 공개 `/obstacles` 응답은 캠핑사이트를 제거하고 캐시하지 않는다. 관리자 인증 뒤에는 키를 POST 본문으로 보내
  전체 목록을 다시 불러오며, 관리자 모드를 해제하면 로드된 캠핑사이트 마커와 검색 데이터도 즉시 제거한다.
- 일반 지도에서 이동이 끝날 때 중심 좌표와 줌을 기기에 저장해 새로고침 뒤 같은 화면을 복원한다. 코스·거리측정·
  장소·강줄기·로드뷰 공유 URL은 저장 화면보다 우선하며, 공유 화면 열람 중에는 일반 지도용 마지막 위치를 덮어쓰지 않는다.
- 전체 Python/Node 회귀 검사와 Worker 문법·dry-run 검사를 통과했다. 모바일 Playwright 12개 시나리오에서 관리자 전용
  캠핑사이트의 로그인/해제 노출 경계와 지도 위치 복원·공유 URL 우선을 실제 브라우저로 확인했다.

  위성지도 자동 전환, 날짜 목록 활성화, 닫기, 댐 수위 팝업에서 기존 버튼 제거를 함께 확인한다.

- 추가 요청에 따라 상수원보호, 수상레저금지, 물놀이관리 자료를 `안전·규제정보`라는 같은 관리군에 포함했다.
  현재 물놀이관리 원천 1,336건은 점 자료이므로 면을 추정하지 않고 대표점으로 유지한다.
- 공식 원천과 관리자 보정을 분리하고, 안정 ID·현재 상태·유효기간·출처·정확도·감사 이력을 공통 필드로 둔다.
  구현은 기준선 백업→공통 스키마→이중 읽기 비교→점 쓰기 통합→안전자료 카탈로그→컨펌된 관리자 화면→전환
  순서로 진행하며, 레거시 삭제는 별도 승인 대상으로 남겼다.

## 거리측정 단축 공유와 코스명 행정구역 표기

- 측정 경로와 거리를 Worker KV의 측정 전용 키로 저장하고 `?measure=m<20자리 해시>`로 여는 단축 공유 방식을
  추가했다. 생성은 현재 활성 회원 또는 관리자만 가능하고 조회는 공개이며, 비회원·저장 실패 시에는 기존 긴 링크로
  자동 폴백한다. 기존 `?measure=<압축경로>&km=...` 링크도 계속 지원한다.
- 코스명 자동 제안의 역지오코딩 결과에서 도·특별자치도를 제외하고 시·군·구부터 표기하도록 바꿨다. 행정단위
  접미사는 유지하고, `수원시 영통구`처럼 시 아래 구가 있으면 두 단위를 함께 보존한다.

## 코스 링크의 지도 미리보기

### 한 일

- 컨펌한 시안대로 코스 공유 카드 이미지를 실제 코스 전체선, 주변 하천, 출발·도착, 코스명, 거리로 구성했다.
- 정적 GitHub Pages의 쿼리별 `<head>`를 바꿀 수 없는 제약 때문에 Worker의 `/c/<코스ID>`가 코스별 Open Graph
  HTML을 제공하고, 실제 사용자는 기존 `canoe.crowdbase.kr/?course=<코스ID>`로 즉시 이동하게 했다.
- 코스 등록·수정 또는 소유자가 코스 상세를 열 때 1200×630 JPEG를 Canvas로 생성해 KV
  `course_preview:<코스ID>`에 저장한다. 이미지 업로드는 해당 등록 코스 소유자 또는 관리자만 가능하다.
- 기존 정적 코스 10개와 운영 등록 코스 46개의 이미지를 `tools/build_course_previews.py`로 일괄 생성해 KV에 넣었다.

### 결정·근거

- 카카오톡 같은 링크 크롤러는 정적 페이지가 로드된 뒤 JavaScript로 바꾼 메타태그를 사용하지 않는다. 따라서
  기존 `?course=` 링크를 그대로 두고 클라이언트에서 제목만 바꾸는 방식으로는 코스별 이미지를 제공할 수 없다.
- 이미지 자체는 공개 코스 경로만 포함하지만 임의 이미지 덮어쓰기를 막기 위해 등록 코스는 현재 소유자와 활성 회원
  상태를 함께 검증하고, 정적 코스는 관리자만 갱신한다.
- 코스 ID 존재만 현재 공개 상태로 보지 않는다. 등록 코스는 현재 `courses` 배열에 있어야 하고, 정적 코스는
  `course_hidden`에 없어야 공유 HTML과 이미지가 제공된다.

### 검증

  육안 확인했다. 생성 이미지는 약 60KB이며 JPEG 시그니처와 KV 저장 버전을 재조회했다.
- 코스별 OG 제목·이미지·리다이렉트와 HTML 이스케이프, 잘못된 ID 거부, 정적 코스 레지스트리 일치,
  삭제·숨김 코스의 현재 상태 확인을 회귀 테스트로 추가했다.

  `main`에 푸시했으며 GitHub Pages 배포가 성공했다. 투어 정적 산출물은

  62,274바이트이며 로컬 생성본과 SHA-256이 일치했다. 모바일 브라우저로 공유 주소를 열면 기존
  `canoe.crowdbase.kr/?course=k1788763953491`로 이동하고 전체 코스선·거리 팝업이 표시되며 오류가 없었다.
- 삭제 후 ID만 과거에 남은 등록 코스 `k1783483717516`의 공유 주소는 운영 Worker에서 `404`를 반환해 현재
